Notes

The puzzle

The 11-by-11 region can be subdivided into various states. A “state” is a connected group of 1 or more squares that is symmetric in some way, be it via rotation or reflection. If every nontrivial rotation or reflection of the plane that takes a state to itself leaves exactly 1 of its squares fixed, then that square is its capitol. (So, for example, a 1-by-3 region has no capitol, nor does the “X” pentomino.)

The cost of traveling from one square to an orthogonally adjacent square in this nation is equal to the size (i.e. number of squares) of the state you are travelling in, or, if travelling between two states, the lesser of the two states’ sizes. A number in a cell denotes the lowest cost of travelling from the numbered square to any state capitol.

After determining the shapes of the states, label each cell with the size of the state it is in. Compute the sum of these values in each row, and submit as your answer the sum of the squares of these row sums (as in the example).

What the sandbox checks

  • States. A state is flagged when it is not connected or has no nontrivial symmetry. Symmetries are tested about the centre of the state's bounding box: ↔ ↕ ↻180, and for a square bounding box also ↻90 ↻270 ⤡ ⤢.
  • Capitol. Marked with a dot when every symmetry of the state fixes exactly one square. The States table says which symmetry spoils it otherwise.
  • Costs. The cheapest route from every cell to the nearest capitol of a valid state, using the current sizes of the states. Unassigned cells are impassable, so costs are only final once the grid is full. A clue is ok when the cost matches, too cheap when a cheaper route already exists (growing a state can still fix this), and pending when the cost is still higher or no route exists yet.
  • Answer. Each cell is labelled with its state's size; the answer is the sum of the squares of the row sums. Unassigned cells count 0 until they are filled.

Shortcuts

  • P paint, E erase, X probe. Right-click always erases. ⌥-click picks up the state under the cursor.
  • N new state, [ / ] previous / next state.
  • ⌘Z undo, ⇧⌘Z redo. One drag is one undo step.
  • S toggle size labels, C toggle cost labels.

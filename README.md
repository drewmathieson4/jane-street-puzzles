# Jane Street puzzles

Tools and notes for [Jane Street's monthly puzzles](https://www.janestreet.com/puzzles/).
One directory per puzzle, named `YYYY-MM`.

Most tools are a self-contained HTML file — no install, no build step. Open it in a browser.

These are **solving aids, not solvers**: they handle the bookkeeping (legal moves, running
scores, rule violations) and leave the deduction to you.
